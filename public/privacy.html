Privacy Policy

loci — a personal note-taking app. Last updated 9 August 2026.

loci is a single-user application run by one individual for their own use. It is not a product offered to the public, and it has no other users.

What is collected

  • The content of text messages the operator sends to the app's own phone number, and notes typed into its dashboard.
  • The phone number those messages are sent from, and the date and time they arrive.
  • Nothing else. There is no analytics, no tracking, no advertising identifier, and no third-party script on any page.

How it is used

Message content is saved as notes so the operator can read it back later. It is used for nothing else. It is not profiled, sold, rented, or shared with any third party for any purpose, and it is never used for marketing.

Where it is stored

  • On an encrypted disk attached to the operator's own server at Fly.io.
  • Mirrored to the operator's own private Google Drive folder as a backup.
  • Message metadata is retained by Twilio, which carries the messages, under Twilio's own privacy policy.
  • Note text is sent to Anthropic's API to generate a daily plan. Anthropic does not train its models on API inputs.

Access requires a password or a one-time code sent to an allowlisted phone number. No one but the operator can read the notes.

How long it is kept

Notes are kept until the operator deletes them. Deleting a note removes it from the app; backup copies age out with the backup history.

Messaging consent

The only person who receives messages from this app is its operator, who set it up for themselves. Consent is not collected from anyone else because no one else is messaged. Reply STOP to any message to stop receiving them, or HELP for help. Message and data rates may apply. Mobile information is never shared with third parties for marketing purposes.

Contact

Questions about this policy go to the operator of this deployment, at the email address on file with the app's Twilio account.
